# Traveloop

The ultimate travel planning and budget management platform.

## Features
- **Dynamic Dashboards**: Visualize your upcoming trips and travel stats.
- **Trip Planning**: Detailed itinerary management and city searching.
- **Budget Tracking**: Manage your travel expenses with ease.
- **Packing Lists**: Never forget an item with smart packing lists.
- **Shared Trips**: Collaborate with friends on your next adventure.

## Tech Stack
- **Frontend**: Next.js, Tailwind CSS, Framer Motion, Lucide Icons.
- **Backend**: Node.js, Express, Prisma, PostgreSQL.
- **Design**: Premium glassmorphism and modern UI/UX.

## Getting Started

### Frontend
```bash
cd frontend
npm install
npm run dev
```

### Backend
```bash
cd backend
npm install
npm run dev
```
